Station 01 · the crucible

Design a tile, then characterize it

Paint walls on the flower. Its 42 outward edges partition into six seams — colored ticks around the rim — and each seam is the complete interface to exactly one neighboring flower in the tiling. The live preview drives pressure in through seam and out through seam ; characterization then drives each seam to unit pressure in turn and measures the steady flux through all six.

Theory guarantee: one linear fluid ⇒ the exact reduced model is the symmetric, row-sum-zero G in the heatmap. The runtime conductances are chain-calibrated: for each direction, real 2-tile and 3-tile composites of the element are simulated at full resolution and the per-hop conductance extracted by length-differencing (1/g = 1/T₃ − 1/T₂), which cancels end effects exactly and bakes in the seam physics that single-tile experiments miss. The star-fit % (from two-port probes) still reports how much cross-seam structure the reduction discards. The coarse runtime uses the star reduction; star fit % says how much survives. Seams make directional elements buildable in v2 — though a rim cell can still carry edges of two seams where they meet, so ports are exact per-edge, approximate per-cell.

Station 04 · the adaptive runtime

Simulate in detail until you can't tell the difference

Everything above assumed one fixed surrogate per element. Here the runtime decides per tile, per tick. The physics now has a real nonlinearity — drying: below a saturation threshold a cell's conductance collapses (donor-side, so wet can still wet dry), so a tile's behavior depends on how wet it is and how hard it's driven. One fitted conductance can't cover that, and nothing pretends otherwise.

So each tile carries a small table of calibration records, each a local fit plus a trust region in operating space. Every tick a tile checks where it is: inside a record's region → run the cheap surrogate; outside → fall back to full 37-cell simulation, watch the real fluxes for a settling period, and commit what it learned as a new record (or widen an existing one that already predicted it). This is ISAT — in-situ adaptive tabulation, the combustion-chemistry algorithm — wearing a hex costume. The source pulses on and off, so the world keeps wandering into regimes it hasn't seen yet.

What to watch: at reset every tile is red — nothing is known, so everything runs in full detail and the twin is doing double work. Records accumulate, tiles flip to surrogate, and the fallback trace decays. Then the source cuts out, the world starts drying, operating points march left into unexplored territory, and the map flushes red again — briefly, because each excursion is also a lesson. Compute is the honest metric: fine cells stepped per tick against the 2,257 the truth pays every tick, forever.

Measured, so you don't have to take it on faith: novelty fallbacks decay 0.31 → 0.00 per tick (a 68× drop) while the audit traffic holds flat at 0.37 — that floor is deliberate and permanent, the price of continuing to check. Steady state runs 83% of tiles on surrogate at 378 of 2,257 cells per tick — 6× less physics — for 15.5% error against the truth running beside it. Slam every tile bone dry, a corner of operating space it has never seen, and the trust check fires 45 fresh fallbacks within a hundred ticks.

Verification, the thing CFD does that we hadn't. Flowers of radius 1, 2 and 3 all tile the plane, so the same physical problem can be re-tiled at three coarse resolutions and the closure's flux error measured against exact fluxes at each. Result: 27.2% → 13.2% → 7.4% as tiles shrink from 37 to 19 to 7 cells — an observed order of ~1.6. The lumped closure is a convergent discretization, not an O(1) correlation, which is the opposite of what I predicted. Error here is controllable by two independent dials: tile size and feature richness.

And a caution the turbulence people would recognise. Keying each seam on (own head, neighbour head) instead of a tile-global operating point cuts the a priori flux error four-fold — 27.2% to 6.7% at this tile size, measured by handing the model exact coarse states. It barely moves the a posteriori error of the running simulation: 15.5% before, 15.8% after. That disconnect is a documented hazard of subgrid modelling — a model that scores better against exact fields need not run better, because in a live simulation the coarse state itself drifts and flux errors interact rather than accumulate independently. The remaining bias is systematic (the surrogate world holds ~18% less fluid than truth), which points at storage and boundary coupling rather than the flux law, and that is the next thing to measure rather than guess.

Where the error actually lives. Mapping per-tile error against distance from the source settles it: 29.5% at the source tile, 22.5% one ring out, decaying monotonically to 4.6% at the far edge. The error is not spread evenly and it is not a timing artefact — it concentrates exactly where the head gradients are steepest. A tile beside the source is genuinely high on one side and low on the other, and a single stored number cannot hold that shape, so it passes the wrong flux onward. The runtime now carries the element's full characterised port matrix with an in-situ amplitude, which cut the record store from 749 entries to 50 and sharpened the learning curve to a 260× decay — but it did not touch this, because a port matrix describes how a tile routes between its seams, not how steeply the field tilts inside it.

One prediction died here. Falling back reconstructs a tile's 37 cells by spreading its single stored number uniformly, so everything the interior knew about its own shape is lost — which should have made the error transient-dominated. It isn't: 19.5% near a pulse edge versus 20.1% deep in steady flow, a ratio of 0.97. The residual is model-form, not internal-state compression, so retained internal modes are not the next rung — richer seam interfaces are. Three of this project's four biggest corrections have come from a measurement contradicting a confident guess.

What this is, formally

Notes for the next scale

This has a name

Auto-characterizing a microstructure into an effective element is computational homogenization (RVE/FE² in FEA; Darcy upscaling in porous media; Thévenin reduction in circuits). With one linear fluid the reduced law is provably linear — G is exact — so the only modeling error is the star simplification at runtime. Real empiricism starts with nonlinear physics (drying, inertia, chemistry): then the sweep fits response surfaces, and tiles with storage hysteresis need internal state variables.

Known limits, by design

① Identification is everything, and we learned it twice. Single-tile probes with clamped seams over-mix (a uniform-head seam is a perfect conductor along its own line) — first the star fit to G leaked 32% on open ground, then even the exact-G runtime leaked 18%, because G itself was measured under uniform-seam conditions the composite never provides. Chain calibration — measuring real 2- and 3-tile composites and length-differencing — cuts the open-world error to ~8% and dam worlds to ~1%. The residual is cross-seam structure and seam-head non-uniformity; the next rung is multi-node seam interfaces (mortar bases). ② Characterization probes tiles in isolation; neighbors impose correlated boundary conditions the ensemble never saw (the closure problem — the fundamental error of all homogenization). ③ Hexagons don't tile hexagons — solved: radius-R flowers (3R²+3R+1 cells, always a Löschian number) tile the plane exactly on a rotated superlattice; v2 runs on it, and the composite build asserts zero cell collisions as a live proof. What remains: seams meet at rim cells, so a cell can carry edges of two seams — ports are exact per-edge, approximate per-cell.

Where it goes

Multi-node seams: the full-G interface runtime is built (toggle it in the twin test) — the next fidelity rung is 2–3 head unknowns per seam (mean + tilt), characterized against tilt modes, to lift the uniform-seam assumption that limits both current modes.

Level 3: a 61-flower world is itself a patch of a hexagonal supergrid — characterize it with the identical procedure (aperture 37 again, another 25.3° of rotation) and measure how error compounds per level. That number decides the whole game.

Nonlinear castings: swap the fine fluid for the pipe model with drying and refit — the first genuinely empirical elements.

RL hook: "design a tile whose G approximates a target" is inverse design with a 37-bit action space and the twin error as a free reward.
